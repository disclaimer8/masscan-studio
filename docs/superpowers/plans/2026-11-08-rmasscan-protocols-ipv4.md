# rmasscan: протоколы IPv4 — план реализации (КАРКАС, заполняет Denys)

> **ОБЯЗАТЕЛЬНЫЙ САБ-СКИЛЛ:** superpowers:subagent-driven-development. Шаги в чекбоксах.
> Каркас от Claude: структура/границы/карта файлов/скелеты TDD на месте; строки **ЗАПОЛНИТЬ:** (ссылки
> `~/masscan/src` файл:строка, байты шаблонов/пейлоадов, значения тестов) вписывает Denys. До заполнения не исполняется.

**Goal:** паритет rmasscan с masscan по типам зондов IPv4 (ICMP, UDP+payloads, SCTP, ARP-скан, префиксы портов) с
рендером их записей во всех форматах вывода и `--readscan`.

**Architecture:** шаблоны/грамматика портов — `rmasscan-core`; приём ответов — `rmasscan-engine`; рендер — существующий
`rmasscan-cli::output` (расширить `Record` и форматтеры).

**Tech Stack:** Rust 1.99.1, workspace `rmasscan/`, без новых крейтов.

**Spec:** `docs/superpowers/specs/2026-11-08-rmasscan-protocols-ipv4-design.md`

## Global Constraints

- `#![forbid(unsafe_code)]` кроме `rmasscan-net`; ноль новых зависимостей; `Cargo.lock`/`deny.toml` без изменений;
  language-guard зелёный; ноль живого трафика/NIC в тестах; приватность публичного репо.
- Сборки/тесты на ноутбуке (Linux); **Windows/macOS clippy+тесты ловит только GitHub CI** (не Linux-гейт ноутбука).
- TDD: красный тест → минимальная реализация со ссылкой на C файл:строка → зелёный.

## Review Focus

- ЗАПОЛНИТЬ: 5 входов/режимов отказа most-likely-first (например: `-pU:53,T:80` смешанный список; UDP-порт без
  пейлоада в таблице; ARP-скан без соседей; запись нового типа в `-oB`, читаемая C `--readscan`; `--readscan` файла
  C с UDP-записью). Каждому — тест в задаче-владельце.
