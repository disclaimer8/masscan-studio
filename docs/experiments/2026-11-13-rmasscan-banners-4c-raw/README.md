# Сырые данные приёмки подэтапа 4c

Живых окон в этой сессии не было (нет стендов и root), поэтому здесь только отчёты фаззера этой сессии
(debug-сборка `rmasscan-lab`, Mac). Остальные свидетельства приёмки — эталоны оракула в
`rmasscan/tests/golden/{tcp-banners,tls-records,x509}` и юнит/e2e-тесты ветки.

## fuzz-tcp-r1/

- Прогон tls (`fuzz tcp --family tls --seed 20261115 --duration 120s --corpus tests/golden/tcp-banners`):
  1 243 590 входов, `CLEAN`, код выхода 0 — консольная строка прогона; JSON-отчёт этого прогона в песочнице
  до диска не дошёл, попытки регенерации прерваны/не уложились в таймаут при загруженной машине, поэтому
  файла `tls.json` здесь нет (цифры — отчёт приёмки, раздел 5).
- `x509.json` — `fuzz tcp --family x509 --seed 20261115 --duration 120s --corpus tests/golden/x509`:
  222 482 входа, находок нет; код выхода 2 — `MEMORY NOT MEASURED` (в этой песочнице нет замеров RSS).

Счётные прогоны framework (3000) и stack (2000) того же зерна — без находок, код выхода 2 по той же причине
(отчёты не сохранялись). Часовые прогоны и живой повтор окон на стендах — NOT RUN, см. отчёт приёмки, раздел 6.

`MANIFEST.sha256` — хэши файлов этого каталога.
