должен быть закрытым результатом) на реальных данных нашла одно расхождение, и оно объяснено кадрами: в `perf.100000.r2` порт
7000 (служба хоста, не слушатель лаборатории) отвечает SYN-ACK (t=277.822917), результат `7000:open` есть; позже в окне
(t=280.099921) Darwin прерывает эмбриональное соединение и шлёт RST,ACK, ack которого по-прежнему равен seq SYN + 1. Это не второй
ответ на зонд: у порта один результат, поэтому RST после SYN-ACK того же порта закрытого результата не требует (правило и тест
`an_rst_that_follows_the_synack_of_the_same_port_needs_no_closed_result`). Других расхождений нет. 418 RST реального
`perf.100.r1` по-прежнему есть среди результатов; мутация без результатов даёт FAIL (тест
`losing_the_real_418_rsts_of_the_archived_perf_100_r1_is_a_behaviour_fail`).
