# Rust-only lab: raw logs

(`linux/`, `windows/`, and the macOS logs here). Home directories are written `$HOME` and the
working copy `$REPO`, as in every other raw-evidence directory; the only edit made to these logs
is that substitution (F4, review item M6), applied to the macOS logs and to `linux/final-*.log`.
Test counts, timings and verdicts are unchanged.
